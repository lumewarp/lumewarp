The database migration runs as Job {{ .Release.Name }}-migrate-{{ .Release.Revision }}; the control plane
becomes ready once it has finished:
  kubectl -n {{ .Release.Namespace }} wait --for=condition=complete job/{{ .Release.Name }}-migrate-{{ .Release.Revision }}

Port-forward the Admin UI and sign in (SSO through lumewarp.controlPlane.oidc.*, or the
break-glass password; the first login matching lumewarp.controlPlane.initialAdminEmail
becomes proxy_admin):
  kubectl -n {{ .Release.Namespace }} port-forward svc/{{ include "stack.controlPlaneName" . }} {{ .Values.lumewarp.controlPlane.service.httpPort }}:{{ .Values.lumewarp.controlPlane.service.httpPort }}

The gateway authenticates with the fixed token of zone {{ .Values.global.zone | quote }} in Secret
{{ include "stack.gatewayTokensSecretName" . | quote }}. The chart created it with a random
48-character token per zone; read the gateway's token with:
  kubectl -n {{ .Release.Namespace }} get secret {{ include "stack.gatewayTokensSecretName" . }} \
    -o jsonpath='{.data.LUMEWARP_GATEWAY_ZONE_{{ .Values.global.zone | upper | replace "-" "_" }}_TOKEN}' | base64 -d
Add more zones with `global.gatewayTokens.zones`; set `global.gatewayTokens.secretName` to use
an existing Secret with the LUMEWARP_GATEWAY_ZONE_<ID>_TOKEN keys instead.

Manual: https://lumewarp.github.io/lumewarp/operations/helm.html
